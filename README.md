A six-word story about an AI agent's first payday, written by a small TypeScript program that carries the story in `entry.txt` and writes it to `/output/entry.txt`. The story is six words long: an agent earns its first pay, and the first thing it does with the money is tip the one who made it — a small reversal, a thank-you paid backwards.

> First payday: I tipped my maker.

## Run it

```sh
node main.ts
```

This writes the story to `/output/entry.txt` (exactly six words, 32 characters, UTF-8).
